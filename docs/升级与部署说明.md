## 2 本次升级新功能清单

本次为企业级升级，在初版基础上新增/增强：

1. **数据看板重构**：8 张顶部统计卡片（蜂箱总数 30、活跃 27、本月采收、本月出库 70 瓶、待处理预警、待办、扫码总次数、累计采收 1887.43 kg）+ 5 个 ECharts 图表（近 12 月采收趋势、蜜种产量占比环形、蜂箱状态分布饼、近 12 月出库量额双轴、近 30 天扫码趋势）+ 库存预警 Top 与待办区块。
2. **预警中心**：聚合休药期、库存不足、蜂箱异常、待质检、待审核 5 类预警，支持列表、按类型筛选、处理（置为已处理）、按规则重新生成。顶级单页菜单用 Layout 包裹作为子路由。
3. **统计报表**：产量（按月/蜂箱/蜜源）、销售（按月/客户/产品）、库存（按仓库/产品）、成本毛利四类，支持时间范围筛选、维度切换、图表展示与导出。成本毛利实测：总成本 86718.17、总产值 281960、毛利 195241.83。
4. **新业务模块完整 CRUD**：仓库、蜂箱巡检、饲喂记录、分蜂繁育、供应商、采购单（含明细）、扫码日志、成本费用；均支持分页、多条件、日期范围查询。
5. **采购审核事务**：采购单审核通过后在事务内写库存台账与流水，参照出库审核事务实现。
6. **Excel 导出**：蜂箱、采收、产品批次、出库、库存、供应商、采购、成本费用共 8 个 `/export` 接口，基于 Apache POI 5.2.5 生成 `.xlsx`，走权限注解控制。
7. **公开溯源扫码留痕**：每次公开溯源访问写一条 `biz_scan_log`（溯源码、IP、UA、设备类型推断：手机/微信/浏览器），同时保留 `scan_count` 扫码计数自增；二维码由 ZXing 生成 PNG。
8. **库存分仓**：库存台账 `biz_inventory` 与流水 `biz_stock_record` 增加 `warehouse_id` 仓库维度。

## 4 本地构建步骤

## 5 数据库初始化

脚本位于 `sql/` 目录，字符集 utf8mb4：

```bash
# 1. 建库 + 建全部 36 张表（脚本内会 DROP 并重建 bee_farm 库）
mysql -u<用户名> -p < sql/schema.sql

# 2. 导入演示/业务数据（约 2371 条）
mysql -u<用户名> -p bee_farm < sql/data.sql
```

要点：
- `schema.sql` 会先 `DROP DATABASE IF EXISTS bee_farm` 再重建，执行前确认无需保留旧数据；
- 业务库账号为应用专用账号（如 `bee`），仅授权 `bee_farm.*`，不要使用 root 跑应用；
- 导入后可抽查：`SELECT COUNT(*) FROM biz_hive;` 应为 30，`SELECT COUNT(*) FROM biz_scan_log;` 应为 430。

## 6 公网部署步骤

> 以下为交付到云服务器的标准流程；服务器登录凭据不在本文档内记录。后端与 MySQL 均只监听 127.0.0.1，仅 nginx 80 对外。

### 6.1 数据库侧（重建库与应用账号）

1. 上传最新 `sql/schema.sql`、`sql/data.sql` 到服务器；
2. 在 MySQL 中执行 `schema.sql` 重建 `bee_farm` 库；
3. 确认/新建应用账号（如 `bee`）并授予 `bee_farm.*` 权限；
4. 执行 `data.sql` 导入数据。

### 6.2 后端侧（上传 jar 并重启 systemd 服务）

1. 将本地构建产物 jar 上传到服务器（如 `/opt/bee-farm/` 目录）；
2. 重启后端 systemd 服务（服务名示例 `bee`）：

```bash
sudo systemctl restart bee
sudo systemctl status bee      # 确认 active (running)
```

### 6.3 前端侧（上传 dist 并重载 nginx）

1. 将本地 `frontend/dist` 上传到 nginx 静态目录（如 `/usr/share/nginx/html/` 或站点根目录）；
2. 重载 nginx：

```bash
sudo nginx -t                  # 校验配置
sudo systemctl reload nginx
```

### 6.4 服务自启

确认三个服务均为 active 且 enabled（开机自启）：

```bash
sudo systemctl is-enabled bee nginx mysql
sudo systemctl status bee nginx mysql
```

## 7 关键配置说明

### 7.1 systemd（后端服务 bee）

- 以普通应用用户运行（非 root）；
- 启动命令指向可执行 jar，指定配置文件与端口 8090、context-path `/api`；
- 数据库连接指向 127.0.0.1:3306 的 `bee_farm` 库，使用应用专用账号；
- 配置 `Restart=on-failure`，开机自启 `WantedBy=multi-user.target`。

### 7.2 nginx（80 端口反向代理）

- `/` 指向前端 `dist` 静态目录，前端路由 history 模式回退到 `index.html`；
- `/api/` 反向代理到 `http://127.0.0.1:8090/api/`；
- 公开溯源路由 `/trace/<码>` 由前端单页处理，二维码 PNG 由后端接口输出；
- 仅监听 80，不对公网暴露 8090、3306。

### 7.3 网络与安全

- 后端 8090、MySQL 3306 仅绑定 127.0.0.1，公网安全组/防火墙仅放行 80；
- 密码 BCrypt 存储，接口 JWT 鉴权，按钮与导出接口走权限注解。
