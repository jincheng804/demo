# 弹窗专项审查与部署说明（第二版）

本次根据“六字标签末字换行、退出确认框几乎铺满屏幕”的反馈，检查全部前端页面的弹窗定义及共享样式，修复 36 个业务弹窗与确认 / 密码提示框的公共布局。后端业务、数据库结构、接口、表单字段、校验条件及提交数据保持不变。

## 已确认的原因与修复

1. **退出登录确认框过宽**：上一版 `.el-message-box` 将 Element Plus 的 `max-width:420px` 改为 `calc(100vw - 32px)`，而组件原有 `width:100%` 仍生效，因此宽屏下会接近铺满屏幕。本版同时约束实际宽度与 420px 上限，窄屏自动留出两侧空间；重新调整标题、正文、按钮的间距，并使用明确的“退出登录 / 取消”按钮。所有删除、审核、处理确认和密码提示框共同使用这套尺寸规则。
2. **长标签换行**：固定 80 / 90 / 100px 标签宽度无法容纳长标签、必填星号及边距，正文的 `overflow-wrap:anywhere` 又允许任意字符断行。本版把 33 个表单改为 `label-width="auto"`（含个人中心两处表单），标签按实际文字宽度自动对齐，保持单行；弹窗正文恢复正常换行。包括“来源采收批次”“采收重量(kg)”“供应商名称”“操作后库存”和带术语提示图标的标签。
3. **弹窗高度与操作区**：全部 36 个业务弹窗居中，设置视口内的最大高度。正文内部滚动，标题、关闭按钮和底部操作区保持可见，适用于较长表单、菜单权限树和多条采购 / 出库明细。
4. **小屏表单**：767px 及以下改为上方标签、下方输入控件，双列表单转单列；校验错误占正常空间，避免覆盖下一行。日期、选择和数字控件约束在可用宽度内；单选 / 多选按选项整体换行。
5. **详情弹窗**：库存流水、采购、质检在小屏变为单列，详情字段名保持单行，内容正常折行；表格保留自身横向滚动。采购、质检、出库详情增加底部“关闭”按钮。出库审批人和时间改为真正的换行，库存流水操作人与时间支持按信息块换行。

## 验证结果与边界

- `npm run build` 通过；交付包已包含本版 `frontend/dist`。
- `frontend/tests/ui-regression.cjs` 共 96 项通过：原有 56 项检查、全部 36 个业务弹窗、公共布局规则、响应式详情监听、真实退出确认框和密码提示框的本地取消交互。测试使用模拟接口，不访问部署系统或写入真实业务数据。
- 将上一版源码包与本版逐字节对比，后端与 SQL 共 211 个文件没有改变，前端依赖声明与锁文件也没有改变。
- 浏览器访问用户提供的 HTTP 地址时，被当前检查浏览器转到 HTTPS，返回 502 “The remote server does not speak TLS”。因此没有完成线上登录、角色权限页面遍历或真实浏览器截图检查，也没有修改部署服务器。本环境不允许直接打开本地 HTML 文件，未通过其他方式绕过该限制。
- JSDOM 不计算真实文字尺寸、媒体查询或视觉布局；自动标签测量可能产生 `unexpected width NaN` 的环境提示。挂载与样式规则检查通过，并不替代不同字体、屏幕和浏览器上的视觉验收。
- 构建仍有原有的大依赖分块提示，不影响构建完成。

## 部署

本次只需要更新前端。

1. 备份现有前端静态文件。
2. 将包内 `frontend/dist/` 的全部内容替换到当前 Web 服务的前端静态目录。保留现有 `/api` 代理和路由回退配置。
3. 浏览器强制刷新，避免旧的入口文件继续引用上一版资源。检查退出确认、装瓶登记、采收登记、库存出入库、采购 / 出库明细和质检详情。
4. 后端程序与数据库无需重新部署或导入。如果现网还有自行修改过的前端代码，请合并本次源文件修改后重新构建，不要覆盖自己的修改。

需要自行编译时：

```sh
cd frontend
npm ci
npm run build
```

需要复现组件回归时：

```sh
cd frontend
npm ci
npm install --no-save --package-lock=false jsdom@24.1.3
node tests/ui-regression.cjs
```

本版仅交付修复后的前端源码与静态文件，线上视觉问题是否全部消失仍需部署后验证。第一版说明中的后端并发库存、单号生成、固定查询上限等事项，本次未改变。
